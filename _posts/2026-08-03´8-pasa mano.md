De acuerdo con AWS D1.1/D1.1M:2025

Requisitos importantes para la fabricación y soldadura del pasamanos de acero

El pasamanos de acero mostrado en la fotografía debe fabricarse y soldarse de acuerdo con un diseño aprobado y con la especificación de soldadura aplicable. Cuando el proyecto especifique AWS D1.1/D1.1M:2025, Structural Welding Code—Steel, deben cumplirse sus requisitos relacionados con el diseño, fabricación, calificación e inspección de estructuras de acero soldadas. 

Los puntos más importantes son los siguientes:

1. Identificación del material base
Se debe conocer el tipo de acero utilizado en los postes, pasamanos, barras horizontales, placas y demás componentes, y comprobar que sea compatible con el WPS correspondiente.


2. Procedimiento de soldadura (WPS)
La soldadura MIG/GMAW debe realizarse conforme a un WPS (Welding Procedure Specification) apropiado. El WPS establece las variables esenciales del proceso, incluyendo proceso de soldadura, material de aporte, gas de protección, parámetros eléctricos, velocidad de avance, posición y otros requisitos aplicables. AWS D1.1:2025 contempla tanto WPS precalificados como WPS calificados. 


3. Calificación del soldador
Cuando lo exijan el código y los documentos del proyecto, el soldador debe estar calificado para el proceso, posición, material y rango de espesores correspondiente. AWS D1.1:2025 establece requisitos específicos para la calificación del personal de soldadura. 


4. Preparación y ajuste de las uniones
Antes de soldar, las superficies deben estar limpias y correctamente preparadas. Los componentes deben estar correctamente alineados y ajustados, con una geometría adecuada de la unión. Un mal ajuste puede provocar falta de fusión, deformaciones, soldaduras insuficientes u otros defectos.


5. Tamaño y capacidad estructural de la soldadura
El tamaño de la soldadura no debe determinarse simplemente por su apariencia. Debe establecerse mediante el diseño estructural y los requisitos del código aplicable, de manera que la unión pueda transmitir de forma segura las cargas que actúan sobre el pasamanos.


6. Unión de los postes con las placas base
Se debe prestar especial atención a la unión entre los postes verticales y las placas base, así como al anclaje de dichas placas a la estructura de soporte. Una soldadura resistente no compensa una placa, un anclaje, un concreto o una estructura de soporte inadecuados.


7. Soldaduras continuas y sanas
Las soldaduras deben presentar una fusión adecuada y una calidad aceptable. Deben evitarse o repararse conforme a los requisitos aplicables las grietas, porosidad inaceptable, falta de fusión, socavación excesiva, solapamiento, golpes de arco y otras discontinuidades no aceptables.


8. Inspección
Las soldaduras terminadas deben inspeccionarse de acuerdo con los requisitos del proyecto y AWS D1.1. La inspección visual constituye una parte fundamental del control de las soldaduras estructurales, y pueden requerirse ensayos no destructivos adicionales cuando estén especificados. AWS D1.1:2025 contiene requisitos específicos para la inspección y aceptación de las soldaduras de producción. 


9. Cargas y dimensiones del pasamanos
AWS D1.1 regula principalmente la soldadura y las conexiones estructurales soldadas; no establece por sí solo todos los requisitos de un pasamanos, como altura, separación entre barras o carga de diseño. Estos requisitos deben obtenerse del código de construcción, estructural, de seguridad o normativa local aplicable. Por lo tanto, deben diseñarse los postes, pasamanos, soldaduras, placas base, anclajes y estructura de soporte para resistir las cargas requeridas.



Conclusión

En el pasamanos mostrado, lo importante no es únicamente que las soldaduras MIG tengan una apariencia uniforme. El sistema completo debe estar correctamente diseñado, fabricado, soldado, inspeccionado y anclado. De acuerdo con AWS D1.1/D1.1M:2025, la soldadura debe estar controlada mediante el WPS correspondiente, materiales compatibles, personal calificado cuando sea requerido, correcta preparación y ajuste de las uniones, tamaño adecuado de soldadura e inspección de las soldaduras terminadas. 

Nota importante: AWS publicó D1.1/D1.1M:2025 como la 25.ª edición, y actualmente también existe D1.1/D1.1M:2025-AMD1, una enmienda a esa edición.
